# Mama Tee's Bakery – Monthly Sales Report

## About
Mama Tee's Bakery is a made-up bakery client with 3 branches. This project builds a tool that produces a monthly sales report.

## Branches
Use these exact names, spelled exactly like this (all in Abuja):
- Wuse
- Garki
- Maitama

## Products and prices (naira)
The bakery sells mostly Nigerian bakery items (bread, chin chin, puff puff, meat pie, sausage roll, fish roll, buns), with fewer pastries and sweets (doughnut, cake slice, croissant, cinnamon roll, banana bread, chocolate chunk cookies).

## Folder layout
- `data/` – input files
- `output/` – results and reports

## Rules
- Never delete or edit the original input file. Treat files in `data/` as read-only.
- Write all results to `output/`.
- Always use the exact branch names above.
